Solana Pulse

live

A safety gateway for AI agents on Solana: check a transaction before your agent signs it, flag known token traps, explain failed swaps. Plain HTTP + MCP from one tool registry, paid per call in USDC with x402.

  • Public benchmark: 9/9 real attack cases caught for the right reason, 0 false alarms
  • 200 real mainnet transactions: 0 false blocks, fees exact 200/200
  • Listed in the official MCP registry and 4 curated lists (all merged)

About

What I'm good at, and what I'm working on

Strengths

  • I ship complete systems. API, database, payments, scheduled jobs, alerts, one-command rollback — on Google Cloud.
  • I measure instead of claiming. Recorded real cases as tests, public benchmarks, track records that include misses.
  • I find real problems in real data. The version 1 bug came from reading blocks, not from an issue list.
  • Careful with money and secrets. Secret Manager only, hard wallet limits and kill switches, check-before-sign, no IPs stored. How ↗
